# Atividade prática (2º tempo)

## Respostas

**1. Quem utilizará o sistema?**  
Os usuários finais, como clientes, funcionários e administradores do sistema.

**2. Cite 3 requisitos funcionais (o que o sistema deve fazer).**
- Permitir que o usuário faça login.
- Cadastrar, editar e excluir informações.
- Gerar relatórios com os dados cadastrados.

**3. Cite 2 requisitos não funcionais (como o sistema deve funcionar).**
- O sistema deve responder às solicitações em até 2 segundos.
- O sistema deve proteger os dados dos usuários por meio de autenticação e criptografia.

**4. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.**  
Porque os requisitos ajudam a entender as necessidades dos usuários, evitando erros, retrabalho e garantindo que o sistema atenda ao que foi solicitado.
